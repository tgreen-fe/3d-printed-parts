# 3D-Printed Parts
A collection of small mechanical parts designed and 3D-printed for various projects. Each includes SolidWorks source, an STL export, and (where relevant) sliced gcode.
- `bike-lights/` – bike light mount (straight and angled)
- `land-rover-door/` – replacement Land Rover door part
- `pill-toothbrush/` – holder base
- `water-fountain/` – tube mounts and water-feature parts
